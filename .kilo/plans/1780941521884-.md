# Safe Read-Only Repository Status Check Plan

## Objective
Perform a non-destructive, read-only status check of the repo and produce a concise safety report.

## Steps (read-only)

1. `git branch --show-current`
2. `git rev-parse --abbrev-ref --symbolic-full-name @{u} 2>/dev/null; git status -sb`
3. `git status --short`
4. `git log --oneline -n 8`
5. `git status -b --short`
6. `git ls-files --others --exclude-standard`
7. `git status --short | grep '^ M' | awk '{print $2}'`
8. Filename-only scan for secret-like names among untracked + modified files:
   - Pattern: `*secret*`, `*api_key*`, `*.env`, `*.pem`, `*.key`, `*.jws`, `*credential*`, `*password*`, `*token*`

## Report Output
- SAFE / UNSAFE verdict
- branch
- ahead/behind
- modified files
- untracked files
- recommended next action

## Constraints
- No edits to repo files
- No commits, no pushes, no rewrites
- Stop and report if anything looks risky or unclear
