## Suggested gate behavior

```yaml
PROVENANCE_GATE_V1:
  applies_to:
    - message.body
    - message.payload.report
    - message.payload.markdown
    - message.payload.summary
    - top-level text payloads

  accepted_forms:
    text:
      starts_with: "OUTPUT_PROVENANCE:"
    json:
      has_key: "output_provenance"
    yaml:
      has_key: "OUTPUT_PROVENANCE"

  exempt_if:
    - payload_kind: raw_command_result
    - payload_kind: binary_artifact
    - payload_kind: heartbeat
    - system_generated: true and signer verified

  failure_action:
    status: blocked
    reason: MISSING_OUTPUT_PROVENANCE
    retryable: true
```

I would use **blocked**, not quarantine, for first rollout. Missing provenance is usually repairable formatting drift, not malicious content.
