The difference you’re noticing is real:

```text

Current needed workflow:
```

## The fix: stop exporting the system; export a case file

For every exterior review, create one compact artifact:

```text
EXTERIOR_REVIEW_PACKET.json
```

It should contain only:

| Field             | Purpose                                  |
| ----------------- | ---------------------------------------- |
| `question`        | What decision do you need?               |
| `target_node`     | One graph node / cluster / claim         |
| `current_state`   | proven / unproven / conflicted / blocked |
| `evidence_paths`  | Files/snapshots/logs to inspect          |
| `proposed_action` | What the lane wants to do                |
| `risk`            | What could go wrong                      |
| `approval_needed` | approve / reject / amend                 |
| `hard_boundaries` | What not to mutate                       |

Exterior lanes should no longer receive “the whole story.” They should receive **one case**.
