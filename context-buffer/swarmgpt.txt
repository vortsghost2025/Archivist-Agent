## If it starts lagging

Lower agent priority instead of killing them:

```bash
renice +10 -p <PID>
```

Or pause one OpenCode process if needed:

```bash
kill -STOP <PID>
kill -CONT <PID>
```

```text
One lane may have two observers.

Headless can verify/sync.

```
