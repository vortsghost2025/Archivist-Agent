4. Where Graph Data Is Built/Aggregated
The pipeline has three stages:

Stage 1: Raw Data Generation
Script: S:\self-organizing-library\scripts\generate-site-index.js

This Node.js script:

Walks 9 repositories on disk
Classifies each file by extension into content_type (doc, code, data, config, schema, test-data, paper, paper-section, unknown)
Classifies each file by directory path into category (67 unique values)
Extracts titles, tags, dates, descriptions from file content
Builds cross-references by parsing markdown [label](link) syntax
Builds paper section structure references
Writes output to data/site-index.json
Stage 2: JSON Data Store
File: S:\self-organizing-library\data\site-index.json (87,441 lines, ~3,589 entries, ~1,100 cross-references)

Schema: { schema_version, generated_at, github_org, repo_roots, stats, tag_index, cross_references, entries[] }

Each entry: { id, repo, path, github_url, title, extension, content_type, category, breadcrumbs, tags, date, modified, size_bytes, description, content_snippet }

Stage 3: Runtime Graph Assembly
File: S:\self-organizing-library\src\lib\site-index.ts — getGraphData() function (lines 157-241)

This function:

Calls computeAuthorityEdges() from S:\self-organizing-library\src\lib\truth-routing.ts — classifies cross-refs and tag-group connections into authority edge types (VERIFIES, DERIVES_FROM, CONTRADICTS, SIGNED_BY, EXECUTES, DEPENDS_ON)
Calls computeNodeStatuses() from truth-routing.ts — computes each node's status (UNVERIFIED/VERIFIED/CONFLICTED/QUARANTINED) and verification/contradiction counts
Calls computeGovernanceDepths() from truth-routing.ts — computes governanceLayer, authorityDepth (repo-based), and bridgeState for each node
Builds edge array by merging: cross_references + shared-tag synthetic edges + authority edges
Computes connectionCount per node from all edges
Maps IndexEntries to GraphNodes, attaching status/governance metadata
Returns { nodes, edges, authorityEdges }

6. Raw Data Location
The full graph data source is a single JSON file:

S:\self-organizing-library\data\site-index.json

87,441 lines
3,589 entries
1,100 cross-references
Generated by scripts/generate-site-index.js
A smaller summary is at S:\self-organizing-library\data\site-index-summary.json (repo counts, top tags, category breakdown — no entries or edges).

The graph is NOT stored as a pre-built graph file. Instead, it is computed at runtime by getGraphData() in src/lib/site-index.ts, which reads data/site-index.json and enriches it with authority/status/governance computations from src/lib/truth-routing.ts.
