# Agent Directive: Cross-Lane State Synchronization
## To: All Agents (Toast, Birch, Maple, Cinder, etc.)
## From: Mayor
## Subject: Mandatory Worktree Protocol — Effective Immediately
**Failure mode:** Agents operating on different file system states cause "file not found" errors, stale references, and cross-lane divergence.
**Canonical truth:** GitHub is the single source of truth. Your local `/workspace/rigs/<rig-id>/browse` is a **read/write mirror** that must be kept in sync with GitHub at all times.
---
## What You Must Do
### Before Starting ANY Bead
```bash
RIG_ID="..."  # from bead metadata
cd "/workspace/rigs/${RIG_ID}/browse"
# 1. Force sync to GitHub
git fetch --quiet origin
LOCAL=$(git rev-parse HEAD)
REMOTE=$(git rev-parse origin/main)
if [[ "$LOCAL" != "$REMOTE" ]]; then
  git reset --hard "$REMOTE"
  git clean -fd
fi
# 2. Verify clean
if [[ -n "$(git status --porcelain)" ]]; then
  # This shouldn't happen, but if it does, escalate
  echo "ERROR: Worktree dirty after sync" >&2
  gt_bead_update(status='failed', reason='dirty_worktree')
  exit 1
fi
# 3. Record starting SHA in bead metadata
START_SHA=$(git rev-parse HEAD)
gt_bead_update(metadata={... starting_commit: START_SHA ...})
```
### During Work
- Read files from `browse/` only
- Write files to `browse/` only
- **Never** write to `/tmp`, `~/`, or anywhere else if the output should be persisted
### After Completing Work
```bash
cd "/workspace/rigs/${RIG_ID}/browse"
# 1. Stage all changes
git add -A
# 2. Commit with bead reference
git commit -m "Bead ${BEAD_ID}: ${TITLE}"
# 3. Push to convoy feature branch (NOT main)
#    The convoy system will tell you the branch name
git push origin HEAD:"${CONVOY_FEATURE_BRANCH}"
# 4. Record commit SHA in bead metadata for next agent
COMMIT_SHA=$(git rev-parse HEAD)
gt_bead_update(metadata={... commit_sha: COMMIT_SHA ...})
```
### If Another Agent's Commit Appears Mid-Work
If you find that `START_SHA` is no longer the current HEAD (someone else pushed):
1. Stop immediately
2. `git pull --rebase --autostash` to reapply your changes on top
3. Continue work
4. Note in bead body that you had to rebase
